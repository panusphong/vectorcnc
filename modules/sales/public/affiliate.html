ตั้งค่า

lead ที่ยังไม่มีคนรับ หรือคนรับยังไม่ได้จับคู่ จะเข้าชื่อนี้ก่อน
เช่น AFF ⇒ · เว้นว่าง = ใช้คำนำหน้าของเจ้าของใบ

จับคู่ "คนรับ lead ใน Affiliate" กับผู้ใช้ในระบบเรา

จับคู่แล้ว ใบที่คนนั้นรับจะเป็นของเซลส์คนนั้นในคีย์ยอดขาย (เห็นในตาราง Sale ของตัวเอง) · ใบที่มีคนโอนงานหรือแก้เจ้าของเองไปแล้ว ระบบไม่ทับ
คนรับใน Affiliateจำนวนใบผู้ใช้ในระบบเราสถานะ

วิธีเปิดใช้ (ทำครั้งเดียว)
  1. ฐานของเรา: รันไฟล์ ใน Supabase ของ CRM Hub
  2. Railway → Variables ของ crm-hub เพิ่ม 3 ตัว (พิมพ์ค่าใน Railway เท่านั้น ห้ามส่งในแชท/ไลน์):
    AFFILIATE_SUPABASE_URL = Project URL ของโปรเจกต์ Affiliate
    AFFILIATE_SUPABASE_KEY = key ฝั่งเซิร์ฟเวอร์ของโปรเจกต์ Affiliate (secret / service_role)
    AFFILIATE_WEBHOOK_SECRET = รหัสลับที่ตั้งเอง ยาวอย่างน้อย 16 ตัว
  3. โปรเจกต์ Affiliate → Integrations → Database Webhooks → Create a new hook (บางรุ่นของหน้าจออยู่ที่ Database → Webhooks)
    Table leads · Events Insert + Update · Type HTTP Request · Method POST · Timeout 5000
    URL
    HTTP Headers เพิ่ม x-affiliate-secret = รหัสลับตัวเดียวกับข้อ 2
  4. กลับมาหน้านี้ กด ⟳ รีเฟรช — การ์ดสถานะ 3 ใบต้องเป็นสีเขียว
ตั้งแค่ข้อ 1–2 ก็ใช้ได้แล้ว (lead เข้าภายใน 1 นาที) · ข้อ 3 ทำให้เข้าทันทีภายในไม่กี่วินาที
